# مجلد الصور (assets)

ضع هنا صورك الخاصة عند توفرها:

- `logo.png` — شعارك الشخصي أو شعار مشروعك.
- `avatar.png` — صورتك الشخصية (تُستخدم عادة داخل قسم About).
- `images/` — أي صور إضافية تريد استخدامها داخل الـ README (لقطات شاشة للمشاريع مثلاً).

ملاحظة: البانر الرئيسي في الأعلى مولّد حاليًا تلقائيًا عبر خدمة `capsule-render` بدون الحاجة لصورة جاهزة.
إن أردت بانر بتصميم خاص بك، ضع صورتك في `banner.png` وبدّل رابط capsule-render في `README.md` بالمسار `assets/banner.png`.
